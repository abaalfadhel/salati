# صلاتي | قضاء ما في الذمة (Salati PWA)

تطبيق ويب تقدمي (Progressive Web App) متكامل، مصمم بالكامل بنظام القراءة من اليمين إلى اليسار (RTL) لدعم ومساعدة المؤمنين والمؤمنات في تنظيم وتوثيق ومتابعة قضاء صلواتهم الفائتة في بيئة آمنة وخاصة ومحفزة.

---

## 🌟 الميزات الرئيسية

1. **الخصوصية المحلية الكاملة (Local-First Architecture)**:
   - تخزين كافة السجلات والأرصدة والملف الشخصي محلياً على جهاز المستخدم حصراً عبر `IndexedDB` و `LocalStorage`.
   - لا يتطلب إنشاء حساب، ولا كلمة مرور، ولا بريد إلكتروني، ولا رقم هاتف.
   - توليد معرّف ضيف محلي آمن ومستقر (`Guest ID`).
   - خلو تام من أي إعلانات أو متتبعات خارجية.

2. **الهوية البصرية والروحية**:
   - ألوان إسلامية راقية: أخضر زمردي داكن (`Emerald`) مع لمسات ذهبية دافئة (`Warm Gold`) وأسطح عاجية هادئة.
   - خطوط عربية أصيلة وعالية الوضوح (Tajawal للنصوص و Amiri للعناوين والآيات).
   - نمط زخرفي إسلامي هندسي هادئ.
   - دعم الوضعين: الفاتح (Light Mode) والداكن (Dark Mode).

3. **شاشة البداية والتهيئة السلسة (Onboarding Flow)**:
   - شاشة ترحيبية راقية تعرض شعار التطبيق ورسالته.
   - إنشاء الملف الشخصي المحلي ومعرف الضيف.
   - تقدير الصلوات الفائتة بالسنوات والشهور (بناءً على 365 يوماً في السنة و 30 يوماً في الشهر) أو بالإدخال اليدوي، مع عرض أعداد الركعات المقابلة وتوضيح شفاف بأنها تقديرات رياضية وليست فتوى ملزمة.
   - حساب دقيق للركعات الخمس: (الفجر: 2، الظهر: 4، العصر: 4، المغرب: 3، العشاء: 4).
   - اختيار طريقة القضاء اليومية من بين 3 طرق:
     1. **الهدف الإجمالي اليومي**: تحديد هدف موحد وتوزيعه.
     2. **الإنجاز التتابعي**: السير وفق الترتيب الشرعي للصلوات (فجر ثم ظهر ثم عصر ثم مغرب ثم عشاء).
     3. **التوزيع المرن المستقل**: تحديد أهداف مستقلة ومخصصة لكل صلاة.

4. **لوحة المتابعة اليومية (Dashboard)**:
   - مؤشر دائري كبير يعكس النسبة المئوية العامة لإبراء الذمة مع الأرصدة (الابتدائي، المنجز، المتبقي).
   - بطاقة جلسة اليوم لمتابعة التقدم اليومي وإمكانية تأجيل أو ترحيل غير المنجز دون حذفه من أصل الذمة.
   - 5 بطاقات مستقلة لكل صلاة مع زر تسجيل إنجاز سريع.
   - سجل زمني فوري للعمليات مع إمكانية التراجع الآمن عن آخر عملية تسجيل.
   - رسائل واقتباسات وأحاديث نبوية محفزة ومطمئنة.

5. **شهادة إتمام قضاء الصلوات المسجلة**:
   - فتح شهادة إتمام رسمية فاخرة بإطار إسلامي ذهبي وزمردي فور تصفير كامل الرصيد المسجل.
   - تتضمن اسم المستخدم، معرّف الضيف، تاريخ الإتمام، تفصيل الصلوات الخمس والركعات المقابلة.
   - إمكانية التصدير المباشر كملف PDF عالي الجودة أو الطباعة الورقية.

6. **الأوسمة ومستويات الهمة والتحديات**:
   - نظام إنجازات محلي حقيقي يوثق الخطوات: أول صلاة، 10، 50، 100، 500، 1000 صلاة، ونسب الإنجاز (25%، 50%، 75%، 100%).
   - مستويات تصاعدية لصاحب الهمة.
   - تحديات شخصية يومية وأسبوعية ومخصصة.

7. **النسخ الاحتياطي والأمان (JSON)**:
   - تصدير واستيراد ملفات النسخ الاحتياطي بصيغة JSON مع تحقق برمجي صارم من الحقول والبيانات قبل اعتمادها لمنع تلف السجلات أو فقدانها.

8. **تطبيق ويب تقدمي (PWA)**:
   - ملف `manifest.json` وأيقونات متوافقة.
   - `Service Worker` للتخزين المؤقت للملفات الثابتة والعمل في وضع عدم الاتصال (Offline).
   - زر تثبيت ذكي داخل التطبيق مع دليل مخصص لمستخدمي هواتف iPhone (iOS Safari).

## 🛠️ البنية التقنية (Architecture)

- **Frontend Framework**: React 19 + TypeScript + Vite.
- **Styling**: Tailwind CSS v4 مع خطوط عربية وتنسيقات RTL مخصصة.
- **Icons**: Lucide React.
- **Persistence**: IndexedDB مع تخزين احتياطي فوري في LocalStorage.
- **PDF Generation**: jsPDF + html2canvas.
- **Testing**: Node.js Built-in Test Runner (`node:test` + `node:assert/strict`) عبر `tsx --test`.

## 📱 التثبيت والاختبار على أجهزة Android و iOS

### على هواتف أندرويد (Android - Google Chrome):
1. افتح رابط التطبيق في متصفح Chrome.
2. ستظهر لافتة التثبيت في أعلى اللوحة، أو اضغط على زر **«تثبيت التطبيق»**.
3. أو اضغط على قائمة المتصفح (نقاط القائمة الثلاث أعلى اليسار) واختر **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**.
4. سيظهر التطبيق كأيقونة مستقلة على شاشتك الرئيسية تعمل بكامل الشاشة وبدون شريط المتصفح، مع إمكانية الفتح دون اتصال بالإنترنت.

### على أجهزة آيفون وآيباد (iOS - Safari):
1. افتح رابط التطبيق في متصفح Safari.
2. اضغط على أيقونة المشاركة (Share) في الشريط السفلي.
3. مرر للأسفل واختر **«إضافة إلى الشاشة الرئيسية» (Add to Home Screen)**.
4. اضغط على **«إضافة» (Add)**.

## نشر PWA

- المسار الافتراضي مضبوط لمستودع GitHub Pages باسم `salati` (`/salati/`).
- عند النقل مستقبلًا إلى نطاق خاص على جذر النطاق، اضبط متغير البيئة `VITE_BASE_PATH` إلى `/` في خطوة البناء في GitHub Actions.
- يتم تسجيل Service Worker ضمن مسار التطبيق، ويُخزّن ملف التطبيق وأصول البناء التي تم تحميلها لتدعم الفتح دون اتصال بعد زيارة ناجحة أولى.
- البيانات تبقى محلية على الجهاز عبر IndexedDB مع نسخة احتياطية في localStorage. استخدم التصدير/الاستيراد داخل التطبيق للاحتفاظ بنسخة مستقلة من السجلات.

قبل اعتبار الإصدار جاهزًا، شغّل `npm run check` وتحقق يدويًا على Android من التثبيت، وإعادة الفتح دون اتصال، وتصدير/استعادة نسخة احتياطية.
